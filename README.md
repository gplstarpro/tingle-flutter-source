# Tingle - Android Social, Dating & Live Streaming App

Tingle is a modern social discovery, dating, and live-streaming application built with Kotlin and Jetpack Compose.

## Features
- **Discovery / Swiping**: Explore profiles, view bios, photos, interests, and swipe to match.
- **Matches & Real-Time Chat**: Connect with matched users and chat in real time.
- **Live Streams**: Browse and join live broadcast rooms, view live viewer counts, send comments and virtual gifts.
- **Moments Feed**: Share updates, photos, and connect with the community.
- **Profile & Settings**: Manage your personal profile and subscription options.

## Tech Stack
- **Language**: Kotlin
- **UI Framework**: Jetpack Compose & Material Design 3
- **Architecture**: MVVM with StateFlow
- **Image Loading**: Coil
- **Navigation**: Compose Navigation
